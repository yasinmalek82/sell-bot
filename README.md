> A premium Telegram sales platform built for modern 3x-ui businesses.

Neo Bot combines subscription sales, customer management, reseller tools, and secure 3x-ui automation in one streamlined Telegram experience.

## Highlights

- Native 3x-ui integration
- Flexible IP limits for limited and unlimited plans
- Base, reseller, and per-reseller pricing
- Dedicated user and reseller experiences
- Wallet, order, and customer management
- Secure web panel and Telegram webhook
- Automated SSL, database, cron, and server setup
- Interactive server management utility

## Deployment

Built for clean Ubuntu 22.04 and 24.04 servers with an automated production installer.

```bash
curl -fsSL https://raw.githubusercontent.com/yasinmalek82/sell-bot/main/install-latest.sh -o /tmp/neo-bot-install.sh && sudo bash /tmp/neo-bot-install.sh
```

The quick installer automatically resolves and deploys the latest stable version.
